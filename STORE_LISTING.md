# Chrome Web Store Listing Draft

## English (US)

### Name
YouTube Filler

### Short description
Fill the YouTube tab with a centered video crop while keeping browser controls visible.

### Detailed description
YouTube Filler adds a small native-looking button to the YouTube player controls. When enabled, the video fills the browser tab viewport using a centered cover crop, so you get a more immersive view without entering real fullscreen.

It is useful when you want the video to occupy the available browser window while keeping tabs, the address bar and window controls visible.

Features:

- Native-looking YouTube player button.
- Centered cover crop to reduce black bars.
- Browser-window mode without real fullscreen.
- Configurable in-page shortcut, with `º` as the default.
- Native browser shortcut support through Chrome/Brave extension shortcuts.
- Escape exits the mode quickly.
- English and Spanish localization.

Privacy:

YouTube Filler does not collect analytics, browsing history, YouTube account data or video information. It stores only the custom shortcut preference in browser extension storage.

## Spanish (Spain)

### Nombre
YouTube Filler

### Descripción corta
Rellena la pestaña de YouTube con un recorte centrado manteniendo visible el navegador.

### Descripción detallada
YouTube Filler añade un pequeño botón con aspecto nativo a los controles del reproductor de YouTube. Al activarlo, el vídeo rellena el viewport de la pestaña del navegador con un recorte centrado tipo cover, para conseguir una vista más inmersiva sin entrar en pantalla completa real.

Es útil cuando quieres que el vídeo ocupe la ventana disponible del navegador manteniendo visibles las pestañas, la barra de direcciones y los controles de la ventana.

Funciones:

- Botón con aspecto nativo dentro del reproductor de YouTube.
- Recorte centrado para reducir bandas negras.
- Modo ventana del navegador sin pantalla completa real.
- Atajo interno configurable, con `º` como valor por defecto.
- Soporte para el atajo nativo desde los ajustes de extensiones de Chrome/Brave.
- Escape sale del modo rápidamente.
- Localización en inglés y español.

Privacidad:

YouTube Filler no recopila analíticas, historial de navegación, datos de cuenta de YouTube ni información de vídeos. Solo guarda la preferencia del atajo personalizado en el almacenamiento de extensiones del navegador.

Enlace opcional de apoyo: https://buymeacoffee.com/enriqueite
