# Privacy Policy

Effective date: 2026-07-03

YouTube Filler is designed to run locally in your browser and avoid collecting personal data.

## Data Collection

The extension does not collect, store, sell, transmit or share personal information.

It does not collect:

- YouTube account information.
- Video titles, URLs, watch history or recommendations.
- Search queries.
- Analytics or telemetry.
- IP addresses or device identifiers.

## Local Browser Storage

YouTube Filler stores only one user preference: the custom in-page shortcut. This is saved with `chrome.storage.sync`, which means Chrome or Brave may sync it through your browser account if browser sync is enabled.

The extension developer does not receive this setting.

## Network Requests

YouTube Filler does not make network requests to external servers. It only modifies the local YouTube page while you are watching a normal YouTube video.

The popup includes an optional external support link to Buy Me a Coffee. Opening that link is a user-initiated action and leaves the extension.

## Permissions

- `storage`: saves the custom shortcut preference.
- `activeTab`: lets the browser command send the toggle message to the active YouTube tab.
- `https://www.youtube.com/*`: injects the button and styles on YouTube pages, with a guard so the feature only activates on `/watch` pages.

## Changes

Privacy policy updates will be published in this repository.

## Contact

For questions, open an issue in the GitHub repository.

# Política de privacidad

Fecha de entrada en vigor: 2026-07-03

YouTube Filler está diseñada para ejecutarse localmente en tu navegador y evitar la recopilación de datos personales.

## Recopilación de datos

La extensión no recopila, almacena, vende, transmite ni comparte información personal.

No recopila:

- Información de tu cuenta de YouTube.
- Títulos de vídeos, URLs, historial de reproducción o recomendaciones.
- Búsquedas.
- Analíticas o telemetría.
- Direcciones IP o identificadores de dispositivo.

## Almacenamiento local del navegador

YouTube Filler guarda una única preferencia: el atajo interno personalizado. Se guarda con `chrome.storage.sync`, por lo que Chrome o Brave pueden sincronizarlo mediante tu cuenta del navegador si tienes la sincronización activada.

El desarrollador de la extensión no recibe esta configuración.

## Peticiones de red

YouTube Filler no realiza peticiones de red a servidores externos. Solo modifica localmente la página de YouTube mientras ves un vídeo normal.

El popup incluye un enlace opcional de apoyo a Buy Me a Coffee. Abrir ese enlace es una acción iniciada por el usuario y sale de la extensión.

## Permisos

- `storage`: guarda la preferencia del atajo personalizado.
- `activeTab`: permite que el comando del navegador envíe el mensaje de activación a la pestaña activa de YouTube.
- `https://www.youtube.com/*`: inyecta el botón y los estilos en YouTube, con una comprobación para que la función solo se active en páginas `/watch`.

## Cambios

Las actualizaciones de esta política se publicarán en este repositorio.

## Contacto

Para cualquier duda, abre una issue en el repositorio de GitHub.
