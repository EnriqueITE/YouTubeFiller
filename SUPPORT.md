# Support

For bugs, feature requests or compatibility reports, use GitHub Issues in this repository.

When reporting a problem, include:

- Browser name and version.
- Extension version.
- YouTube URL type, for example a normal `/watch` page, playlist, live stream or premiere.
- What you expected to happen.
- What happened instead.
- A screenshot if the issue is visual.

Optional support link: https://buymeacoffee.com/enriqueite

# Soporte

Para errores, sugerencias o problemas de compatibilidad, usa GitHub Issues en este repositorio.

Al informar de un problema, incluye:

- Nombre y versión del navegador.
- Versión de la extensión.
- Tipo de URL de YouTube, por ejemplo una página normal `/watch`, playlist, directo o estreno.
- Qué esperabas que ocurriera.
- Qué ocurrió en su lugar.
- Una captura si el problema es visual.

Enlace opcional de apoyo: https://buymeacoffee.com/enriqueite
